Ještěd scene

Ještěd Tower is situated on a hill created using a GIS plugin, which allows for real-world accurate terrain populated with optimized trees and volumetric fog. An additional sense of fog depth is added in Blender's compositing tab using a generated depth map.

Mushrooms scene

3D-modeled mushrooms with procedurally generated materials have been integrated into a 3D scan of a forest created using photogrammetry. The forest is further enhanced with moss generated using geometry nodes in Blender.

Explicatio

Explicatio is a web app designed for creating papercraft sheets. Users can input a 3D model and manually mark the edges for cutting, along with enumerating edges that are then complemented by generated flaps. The unwrapped parts can be efficiently packed and supplemented with images and text.

Unity mobile game

This 3D mobile game was created as a team school project, which I led. The game mechanics are based on an isometric view, allowing players to make moves that wouldn't be possible with a perspective camera. Although the creation of game levels was tricky, we successfully implemented them to demonstrate all the game mechanics effectively.
